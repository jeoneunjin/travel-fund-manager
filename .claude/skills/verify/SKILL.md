---
name: verify
description: CLAUDE.md의 Commands 섹션에 정의된 lint/타입체크를 실행해 코드 상태를 검증한다. 기능 변경이나 리팩터링은 하지 않는다.
allowed-tools: Bash, Read
---

1. 다음 명령을 순서대로 실행한다.
   - `npm run lint`
   - `npx tsc --noEmit`
2. 코드는 수정하지 않는다. 기능 변경, 리팩터링, 자동 수정(`--fix` 등)을 하지 않는다.
3. 모두 성공하면 실행한 명령과 결과만 짧게 보고한다 (예: 통과 여부, 경고 수).
4. 실패하면:
   - 실패한 명령과 에러 메시지를 그대로 보여준다.
   - 원인을 간단히 짚는다.
   - 최소 수정안을 제안만 하고, 승인 없이 파일을 수정하지 않는다.
5. 장황한 설명 없이 결과 중심으로 짧게 보고한다.
