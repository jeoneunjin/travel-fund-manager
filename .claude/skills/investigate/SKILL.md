---
name: investigate
description: 오류 원인과 영향 범위를 조사한다. 명시적 승인 전에는 파일을 수정하지 않는다.
allowed-tools: Bash, Read, Grep, Glob
---

1. 오류 메시지와 재현 조건을 요약한다.
2. 관련 파일을 최소 범위로 탐색한다 (git diff --stat, grep 우선, 전체 파일 읽기는 필요할 때만).
3. 가능한 원인을 우선순위와 근거로 정리한다.
4. 수정 후보 파일과 최소 수정안을 제안한다.
5. 테스트 또는 재현 명령을 제시한다.
6. 파일 수정, 패키지 설치, DB 변경은 수행하지 않는다.
